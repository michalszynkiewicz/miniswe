# Model scoreboard

Which local models we have tried with miniswe and how they did, per miniswe
version. One section per version, tables inside.

**The benchmark** (unless a row says otherwise) is the internal docker bench,
`scripts/run-benchmark-docker.sh`: the agent must add a
`--system-prompt-override` CLI flag to miniswe itself, inside a 57-minute
timeout. Score is PASS/6 over six checks — `cargo check`, `cargo build`,
flag present in `--help`, flag parses, `cargo test`, and a **smoke** run that
must make the binary answer `PONG_42` through the new flag. Smoke is the only
check that proves the feature works end to end; 5/6 with smoke FAIL usually
means "the flag exists but is wired to nothing".

Result dirs live under `benchmark_results/docker_<timestamp>__<model>/`.

## miniswe 0.1.0 — `context-improvements` @ `3a73d74` (2026-08-21)

Lineage: lazy compaction, diff-echo on `replace_range`, full debugger stack
(multifire + judge + REWIND), skill router / step-cursor pipeline, summarizer
guards, `model.thinking` arm (uncommitted as of 2026-08-22). The bench builds
from the working tree, so runs are listed with their date; the 07-14 gemma
runs predate the skill-router commit, which is inert on this task anyway (no
skills involved).

**Harness fixes (08-23 afternoon, `29577c4` `e6025f8` `3fc77fa` `1879294`).**
Four gaps exposed by Devstral runs 3–4, each its own commit: period-3/4
tool-call cycle detection with window-detector escalation; stale LSP parse
errors after `revert` dropped; a truncated tool call is never persisted
(stubbed + "not executed" result), `refactor`/`file`/`code` arguments are
capped at 4096 chars in the stream, and consecutive parse failures scrub
history then abandon the turn; the debugger's final-report request is
sanitized (Devstral's template read `tool → user` as `user → user` → 500).
Rows marked *harness fixes* ran on that binary.

**Bench-script fix (08-23, commits `2fdc48c` + `88ba610`).** Until 08-23 the
docker script defaulted the reactive debugger and auto-revert OFF and
`gate_context_reset` ON (June A/B values) while the code defaults are on/on/off,
and its done-gate ran the built binary with a bare `hello` that Muse Glimmer
answers with a canned greeting regardless of the override. Rows marked
*script-default flags* below benched that configuration; rows marked
*code-default flags* / *gate v3* are under the fixed script. Re-runs after the
fix are listed as separate rows.

### Nemotron 3.5 Lightning — why it is out

- **Never finished a run inside 57 minutes**, instruct or thinking, with or
  without the template fix (gemma 26B finishes in 5–8 min).
- **Whitespace flood**: the model emits thousands of blank lines at the
  `...:` juncture before an edit, burning the whole 8k output budget per
  occurrence. Root cause is in NVIDIA's own chat template (prefills
  `<think></think>` with no trailing newline in non-thinking mode); adding
  the newline fixes instruct mode (0/4 floods on the exact replay) but
  **cannot cover thinking mode** — the thinking run ended in a 13,005-line
  flood.
